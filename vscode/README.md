# VS Code setup (manual / merge)

Callum Slate colours, JetBrainsMono Nerd Font and block cursor for VS Code on Windows.
Applied as overrides on top of the **GitHub Dark** theme (`github.github-vscode-theme`).

Merge `settings.json` into `%APPDATA%\Code\User\settings.json` (from WSL:
`/mnt/c/Users/<you>/AppData/Roaming/Code/User/settings.json`). Back up the existing file first.
Per-machine settings (e.g. `remote.SSH.remotePlatform`) are deliberately not included.
